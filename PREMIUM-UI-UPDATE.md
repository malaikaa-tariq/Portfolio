# Premium UI update

This package contains the complete React/Vite project, including both `src` and `public` folders.

## Project presentation improvements

- Every project appears in its own structured card.
- All project cards use equal-height containers and aligned content.
- Technical drawings, plans and renders use `object-fit: contain` so they are not cropped.
- Project detail pages place the cover image and project information inside one premium presentation panel.
- Galleries preserve original image proportions inside separate media containers.
- Cover images are automatically removed from galleries so the same image is not repeated.
- Duplicate paths inside each project gallery are removed before rendering.
- Filter and search controls are placed inside a dedicated toolbar container.
- Service, education and preview cards use upgraded borders, spacing, shadows and hover states.
- Desktop, tablet and mobile responsive layouts are included.

## Run

```bash
npm install
npm run dev
```
